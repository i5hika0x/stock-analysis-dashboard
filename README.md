 Indian Stock Market Analysis Dashboard

This project analyzes Indian stock market data and compares selected stocks with the NIFTY 50 index. It provides insights and basic investment suggestions.

 Features:
* Stock comparison
* NIFTY 50 benchmarking
* Returns calculation
* Best stock detection
* BUY / HOLD suggestion
* Streamlit dashboard

 Tech Used:
 Python, Pandas, NumPy, Matplotlib, yFinance, Streamlit

Conclusion:
Helps in stock analysis and decision-making.
